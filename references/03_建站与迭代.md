# 建站与迭代

## 目录约定

```
<站点>/
  index.html  site.config.js  css/  js/  tools/
  assets/
    bg.webp                 背景底板
    clips/gaze/0001.webp…   追视
    clips/t1/ … t4/         衔接片段
    works/                  作品图（16:10）
  plan.md                   规划（不发布也行）
```

素材换成自己的以后，删掉 `assets/demo/`，`check-site.mjs` 会提醒还在用占位素材的地方。

## site.config.js 字段

| 字段 | 作用 | 怎么填 |
| --- | --- | --- |
| `theme.bg` | 页面底色 | **必须等于视频背景色**（`frames.py` 报的四角色），否则页面和画布之间有色差 |
| `theme.accent` / `accent2` / `accent3` / `accent4` | 四个强调色 | 从参考图取：主按钮色、描边/色块色、点缀色 |
| `theme.fontDisplay` / `fontHand` / `fontBody` | 大标题 / 手写注释 / 正文 | 英文字体在前、中文字体在后兜底；改了字体同步改 `fontsHref` |
| `stage.background` | 背景底板 | 加载前显示，也用于没有帧时兜底 |
| `stage.focusX` | 横向焦点 | 窄屏裁切时保留角色所在的横向位置 |
| `stage.portraitZoom` / `portraitHeadY` | 手机竖屏 | 角色放大倍数（默认 1.7）、头部落在屏幕高度的比例（默认 0.27）；设 `portraitZoom: 0` 关闭竖屏布局 |
| `stage.ripple` | 鼠标划过的扭曲 | `mode: 'reactbits'`（默认，React Bits「Ripple Distortion」）：划过留下旋转的波纹、点击向外扩散。需先运行 `scripts/fetch-reactbits.mjs <站点>` 下载组件，没下载时自动用 liquid。参数名与 React Bits 官网调节面板一致（brushSize 刷子尺寸、strength 力量、swirl 漩涡、rings 戒指、spread 传播、fade 褪色、spacing 间距、dispersion 分散、clickStrength 点击强度、quality 质量），可以在官网调好照抄；**`grayscale` 要关**（原组件默认开，整张图会变灰）。备选 `liquid`（液体推开 + 彩虹色散）、`ripple`（水波纹），这两种的 `strength` 用 1 左右 |
| `ui` | 界面固定文字 | 默认英文；中文站改 `cta`、`top`、`close`、`viewWorks`、`all`、`viewProject`，并把 `meta.lang` 改成 `zh-CN` |
| `stage.gaze` | 追视 | `keys` 自动生成或标定；`head` 是头在画面中的位置（0–1） |
| `stage.transitions` | 衔接片段 | `to` 版块从屏幕底部进入到顶部的过程中播完；`span` 调播放距离（默认 0.85 屏）；只有姿态图时加 `blend: true` |
| `sections.<id>.decor` | 手绘装饰 | 见下节 |
| `sections.hero.bubble` | 角色对话气泡 | `lines` 轮播，`hover` 悬停按钮时显示，`offset` 相对头部的位置（`x` 为正时气泡在头右边，尾巴自动朝左） |
| `sections.hero.titleScale` | 首屏大标题缩放 | 名字超过 5 个字母、标题折行时设 0.5–0.7 |
| `sections.hero.scrollX` | 底部滚动提示位置 | 默认居中（50）；角色下半身挡住时往文字一侧挪，如 40 |
| `cursor.trail` | 光标拖尾 | `true` 画荧光笔拖尾；`'auto'` 只在没有水波时画 |

标题数组每一项是一行；`{{词}}` 给这个词加手绘圈。

## 手绘装饰 decor

每个版块一个数组，元素是：

```js
{ type: 'star', color: 'accent', x: 84, y: 12, size: 34, rot: 10, fill: true }
```

- `type: 'img'`：贴纸图片（小卡通角色、手绘配饰），`src` 指向透明底 webp，`size` 为像素宽度，会轻轻浮动。
- `type`：`star` `sparkle` `crown` `bolt` `squiggle` `zigzag` `loop` `arrow` `smiley` `heart` `spiral` `rays` `dash` `circle` `underline` `plus`（线稿，进场时一笔画出，之后手绘抖动），`blob`（颜料色块，`size` 单位是 vw，边缘缓慢变形），`note`（手写注释，`text` 里可用 `\n`）。
- `x` / `y`：所在版块宽高的百分比（可以是负数，让色块出血到屏幕外）。
- 手机竖屏单独处理：`m: { x, y }` 给手机换一个位置；`mobile: false` 在手机上隐藏。桌面上放在角色旁边的涂鸦，到手机上常常会压到文字或撑出屏幕，用这两个解决，不用为了兼顾两端把它挪到很别扭的位置。
- 想要更新的形状：在 `js/decor.js` 的 `DOODLES` 里加一条 100×100 格子里的 SVG 路径。

摆放原则：涂鸦围着标题和角色"点缀"，不压在文字和角色脸上；色块放在屏幕角落、一半出血；一屏 6–10 个就够，多了显乱。换风格（比如极简、科技感）时，直接把 decor 清空或只留一两个色块。

## 风格从参考图来

拿到用户的参考图后，先写下这几项，再改 theme 和 decor：

1. 底色与面板色（深/浅、纯色/纹理）。
2. 2–4 个强调色各用在哪（按钮、描边、色块、点缀）。
3. 标题字体气质（手写马克笔 / 粗黑压缩 / 衬线 / 像素）→ 选 Google Fonts 里最接近的英文字体 + 一个中文字体。
4. 装饰语言（涂鸦、色块、网格、光晕、噪点……）和密度。
5. 角色画法（2D 粗描边 / 3D 黏土 / 插画水彩）——这一项要写进素材提示词。

参考图是别人的作品时，只取风格方向，不照搬对方的角色、名字、文案和版面。

## 预览与检查

```bash
cd <站点> && python3 <skill>/scripts/serve.py 8000   # 浏览器打开 http://localhost:8000（不缓存，改完刷新即生效）
node <skill>/scripts/check-site.mjs .
```

必须用本地服务器打开（直接双击 index.html 时，浏览器会拦截模块脚本）。

自己先截图核对一遍再交给用户（桌面 1280×720 和手机 390×844 各一轮）：

```bash
node <skill>/scripts/shoot.mjs http://localhost:8000 shots '[{"wait":4000},{"move":[1100,120]},{"wait":800},{"shot":"hero"},{"sec":"about","dy":600},{"wait":1500},{"shot":"about"},{"sec":"folder"},{"wait":1500},{"shot":"folder"},{"sec":"works","dy":900},{"wait":1500},{"shot":"works"},{"sec":"outro","dy":2000},{"wait":2500},{"shot":"outro"}]'
```

不要用 Chrome 自带的 `--screenshot`：它只按需渲染，溶解和进场动画会停在半路，截出"重影"。

从头滚到尾，逐项看：

1. 首屏：鼠标绕头一圈，8 个方向都转得过去；鼠标停下几秒后回正；对话气泡位置不挡脸。
2. 往下滚：角色先回正，再开始衔接；衔接开始和结束时不跳。
3. 履历：年份随滚动切换，文字在角色另一侧。
4. 作品目录：点开、卡片展开、背景虚化；ESC 和关闭按钮都能收起；点类目卡跳到作品并筛选。
5. 作品：横向轮播跟手；点卡片出详情；分类标签可切换。
6. 结尾：角色不被联系方式面板挡住；技能图标不压角色。
7. 手机尺寸（390×844）：角色在上半屏，文字在下半屏；气泡不出屏。

## 常见问题与改法

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 鼠标从某个方向移到另一个方向时卡一下或闪一下 | 缺方向，或两方向在时间轴上隔得远，走了溶解 | 补齐 8 个方向；调大 `maxWalk`；检查 keys 帧号 |
| 离开首屏进入下一段时角色姿态对不上 | 追视没回正就开始衔接 | 确认 keys 首帧是正面；`transitions[0].span` 调小，让衔接晚一点开始 |
| 衔接开头/结尾跳一下 | 视频首尾帧与关键图不一致 | 重新生成，首尾帧都上传关键图；或剪掉多余的头尾帧 |
| 背景在片段之间闪 | 各段背景不是同一张 | 所有片段统一用背景底板；`theme.bg` 设成背景色 |
| 文字压在角色脸上 | 版块 `side` 与角色位置冲突 | 改 `side`，或改姿态关键图里角色的位置 |
| 鼠标划过时糊成一片 / 范围太大 / 有黑色拖尾 | 刷子太大、传播太远 / 特效把画面压暗 | reactbits：`brushSize` 调小（50–80）、`spread` 调小（3–5）、`rings` 调大让纹路更细；`grayscale: false`；不要再叠 `cursor.trail: true`。liquid：`radius` 0.03–0.05 |
| 鼠标划过没有效果 | 没运行 fetch-reactbits，或浏览器不支持 WebGL2 | 控制台会提示；运行 `node scripts/fetch-reactbits.mjs .`；不支持时自动退回 2D 拖尾 |
| 首屏加载慢 | 帧太多太大 | `frames.py --width 960 --fps 20`；追视控制在 120 帧内 |
| 手机上角色太大或太小 | 竖屏放大倍数不合适 | 调 `portraitZoom`、`portraitHeadY` |
| 中文标题显示成别的字体 | 大标题英文字体没有中文字形 | `fontDisplay` 里英文字体后面跟一个中文字体 |

## 给用户改的时候

- **一次只改一类问题**，改完让用户看了再改下一类。
- 用户说得模糊时（"不够高级""再炫一点"），给 2–3 个具体方向让他选（例："换成更粗的标题字体""背景加一层慢慢流动的色块""作品卡片悬停时放大并倾斜"），不要自己猜一大堆一起改。
- 已经满意的部分不要顺手动。
